## Taken

- Type is the architecture. A huge wordmark and project names carry hierarchy, so kinetic scale is how you find work, not a decoration on a quiet headline.
- The same work can be reread as vertical, horizontal, or grid. Mode is a type-and-list change, which is why the page can stay one document while the reading order moves.
- Named projects sit as a column under the word. Claims without shipped names would be theatre; the type is loud because the work is specific.
- Chrome stays small next to the type. Nav does not compete with the names the hiring scan is there to judge.

## Rejected

- The exact wordmark, the three-mode theatre, and award-site chrome. Signature layout.
- Oversized type on every heading of a product app. One loud name as wayfinding transfers; a settings page of billboard words does not.
- Implementation recipes for split or scramble text. Record "type is the layout", not a timeline to copy.

## Not applicable here

- Store when studio or campaign marketing uses scale of type as structure, with a list that can change mode. Wrong for checkout, docs, or public-sector services.
