## Taken

- Agent entry points (docs, auth, llms.txt, OpenAPI, skills index) are first-class navigation, not footer afterthoughts.
- API basics sit as a short contract: base URL, auth shape, submit endpoints, poll cadence, credit behaviour.
- Machine-readable surfaces and human docs are peers, which fits buyers who ship with agents.
- Async task polling is explained once, then reused across modalities instead of separate product stories.
- Errors, authentication, and quickstart are named as jobs rather than buried in a blog.

## Rejected

- Cinematic generative-video marketing as the default for an API gateway. Clarity of routes wins.
- Brand mascot or signature illustration systems to copy.
- Equal marketing cards for every model modality when one HTTP contract is the product.

## Not applicable here

- Store when designing developer or agent-facing API entry pages. Wrong for consumer threat marketing or editorial portfolios alone.
