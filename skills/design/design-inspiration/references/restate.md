## Taken

- The visual is the failure path made obvious: with the runtime, a crash resumes; without it, the happy path is a lie. Comparison that explains a mechanism, not a feature checklist.
- Code and logs are the proof. This audience reads traces; an illustration of "resilience" would say nothing.
- Two actions, ranked by job: Get started, then Read docs. Engineers often want the docs second, not a sales call.
- Claims later in the page carry numbers (latency, throughput). The hero can stay qualitative if the body is checkable.
- A sans plus a mono for code. Four weights. Spacing is 4/8 with hairlines. Modest-to-medium radius; shadows are light.

## Rejected

- The announcement-pill treatment, the primary-button hue, and the headline display face. Identity. Three families is already a lot; substitute, do not import.
- A cookie modal covering the product comparison. The comparison is the reason to stay; covering it is a first-paint failure.
- Repeating the same testimonial set in multiple carousels. One well-attributed quote beats a loop.

## Not applicable here

- Store-only pass. Apply when a product is named. This is a runtime marketing page. The operator console, if any, was not this read.
