## Taken

- Ownership and governance land in the first viewport: open source, runs on your machine, no subscription, stewarded by an independent nonprofit. Constraints are the product story.
- Three ranked actions (Get started, Read the docs, Who is behind) keep install, learning, and trust as separate jobs instead of one overloaded CTA.
- Install is a tabbed path (Apps, One-liner, npm, Hackable) so the same section serves installers and people who read source.
- Mixed typography in the headline (sans for the claim, italic for one stressed word) creates hierarchy without a second competing visual system.
- Social proof is long and specific (named people, concrete outcomes), not three equal feature cards.

## Rejected

- Lobster mascot, wordmark, and signature orange/coral accent as identity to reuse.
- ASCII-art hero ornament as a required motif for every developer tool.
- Dark-theme-only as the default for all agent products. Light mode exists; the transferable lesson is ranked install paths and ownership copy.

## Not applicable here

- Store when marketing a local-first or open-source agent with multiple install methods. Wrong for dense operator tables or a quiet personal blog index alone.
