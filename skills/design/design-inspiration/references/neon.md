## Taken

- Agent readers are addressed directly: current page overrides stale training, with install and task routing stated up front.
- Primitives are listed as short contracts (Postgres, auth, Data API, functions, storage, AI gateway) before marketing adjectives.
- A goal-to-doc table turns the home into a router for jobs rather than a scroll of features.
- Safety rails ("ask a human before") mark destructive actions without hiding power-user paths.
- Machine interfaces (MCP, REST, llms.txt, skills) sit beside human docs as peers.

## Rejected

- Soft purple SaaS gradients as a default for developer infrastructure.
- Brand wordmark and signature illustration to reuse.
- Equal feature cards when a task table already maps goals to pages.

## Not applicable here

- Store when designing agent-first or docs-led developer infrastructure homes. Wrong for consumer wellness memberships or film studio portfolios.
