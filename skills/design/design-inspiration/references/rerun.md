## Taken

- "When to use" states fit and non-fit before features, which helps technical buyers scan fast.
- Open-source SDK and Hub are separated so free local craft and production cataloging stay distinct jobs.
- Modalities are named as data types (images, point clouds, tensors, time series) rather than vague AI adjectives.
- Agent resources (docs map, corpus, MCP for the Viewer) sit beside human entry points.
- Language APIs, CLI, examples, and source are ranked as install paths instead of a single hero CTA.

## Rejected

- Soft purple generative-AI marketing as the default for robotics tooling.
- Exact brand mark and illustration identity.
- Equal bento cards when a docs router already maps tasks.

## Not applicable here

- Store when designing technical multimodal data or robotics tooling homes. Wrong for consumer wellness memberships or indie studio taste pages alone.
