## Taken

- The product is the transition. A live prompt and canvas sit under a short headline so a buyer sees state change (compose, generate, publish) instead of a static screenshot.
- Ranked actions: get started, then download. They share a row but not a weight.
- Later sections swap agent jobs (design, CMS, code) in the same frame. Context stays: one canvas, a new job, not a new page for each capability.
- Type is few sizes on a dark field. Motion is reserved for the demo, so chrome does not animate independently of the product.

## Rejected

- The glowing prompt chrome and brand wordmark. Identity.
- Ambient glow behind a video as a substitute for a decision. Light that never explains a state is decoration.
- Cookie UI competing with the hero. Consent should not sit on the first claim.

## Not applicable here

- Store when marketing a canvas or site builder where seeing a change is the argument. Wrong for a records list or a regulated form.
