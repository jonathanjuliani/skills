## Taken

- The object is spatial, so the marketing page shows a canvas rather than a screenshot of a list. Choose canvas only when the work really is spatial.
- One primary action (Get started), repeated. Secondary paths (explore design tools, explore build tools) are named and visibly secondary.
- Skip to main content, and a pause control on the hero motion. If something loops, the user can stop it.
- A specific number where they make a scale claim, with a date on the data. Fortune-500 usage is checkable; "loved by teams" is not.
- Sans plus a mono. Weights stay in a narrow band. Spacing is a clean 4/8 base. Pills on controls, modest radius on cards.

## Rejected

- The wordmark, the multicolour brand, and the named families. Those are identity.
- Variable-font weight numbers from the scrape. They are not a scale to copy.
- An empty canvas as first paint while the demo loads. A canvas with nothing on it reads as unfinished, not as craft.
- Ambient animation that does not explain a change. If the canvas is the product, show a tool being used, then stop.

## Not applicable here

- Store-only pass. Apply when a product is named. A canvas marketing page is the wrong reference for a records list or a dense table.
